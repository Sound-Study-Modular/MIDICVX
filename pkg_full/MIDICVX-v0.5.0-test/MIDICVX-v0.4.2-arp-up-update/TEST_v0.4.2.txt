MIDICVX v0.4.2 TEST

1. Build for DIP ATmega328P:
   make clean && make MCU=atmega328p

2. Flash:
   avrdude -c usbasp -p m328p -B 100 -U flash:w:build/midi_cv_x.hex:i

3. LIVE test:
   - Power cycle.
   - Play MIDI notes. CV and gates should behave normally.

4. Enter ARP UP:
   - Briefly press and release Program once.
   - Hold C, E and G on the MIDI keyboard.
   - Notes should not advance until external clock pulses arrive.

5. Clock test:
   - Patch a 3.3 V or 5 V clock/trigger into the former CLOCK OUT jack.
   - Expected sequence: C, E, G, C, E, G...
   - LED beside the jack follows raw input pulses.
   - Lower red LED flashes on accepted transport ticks.
   - Yellow gate LEDs show generated gate activity.

6. Return to LIVE:
   - Release held keys.
   - Briefly press Program again.
   - Normal immediate MIDI-to-CV behavior should return.
