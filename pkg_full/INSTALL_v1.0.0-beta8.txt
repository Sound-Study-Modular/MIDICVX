MIDICVX v1.0.0-beta8

Replace these files in ~/Desktop/foundations:
  main.c
  playback.c
  playback.h
  settings_layout.h

Build:
  cd ~/Desktop/foundations
  make clean
  make MCU=atmega328p

Flash:
  avrdude -c usbasp -p m328p -B 100 \
    -U flash:w:build/midi_cv_x.hex:i

Split behavior:
  Default split is MIDI note 36.
  Notes below the split go to CV1/GATE1 bass.
  The split note and all higher notes go to CV2/GATE2 arp.

Learn a new split:
  Hold or play the desired lowest arp key during the first second after power-up.
  If several Note On messages arrive, the lowest note is stored.
  Both gate LEDs blink three times after saving.
  With no startup Note On, the previously stored split is used.
