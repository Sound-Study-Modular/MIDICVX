MIDICVX v0.3.0 — UP ARPEGGIATOR TEST

Build for DIP ATmega328P:
  make clean && make MCU=atmega328p

Flash:
  avrdude -c usbasp -p m328p -B 100 -U flash:w:build/midi_cv_x.hex:i

Test:
1. Power up. Module begins in LIVE mode.
2. Confirm ordinary MIDI-to-CV still works.
3. Short-press Program once. MIDI LED should remain steadily lit: ARP UP mode.
4. Send MIDI START followed by MIDI CLOCK.
5. Hold notes on the first configured MIDI channel, for example C, E, G.
6. CV/Gates should play C-E-G-C-E-G, advancing once per 6 MIDI clock bytes.
7. Short-press Program again. MIDI LED returns to normal message flashes: LIVE mode.
8. Long press (3 seconds) still enters the original configuration mode.

Known alpha limitations:
- Arp uses the first configured MIDI channel only.
- MIDI START is required before clock advances the arp.
- External modular clock input is not included yet.
