MIDICVX v0.4.2 — REAL ARP UP IMPLEMENTATION

This is not a placeholder or skeleton.

Implemented behavior:
- LIVE mode passes MIDI Note On/Off to the original MIDI-CV engine.
- Short Program-button press toggles LIVE <-> ARP UP.
- In ARP UP, MIDI Note On/Off updates a real 128-note held-note table.
- External clock rising edges on PC1/PCINT9 are queued by transport.c.
- The main loop calls Playback_TransportTick() once per accepted pulse.
- Playback_TransportTick() selects the next held note in ascending order,
  wraps to the lowest note, releases the previous generated note, and
  outputs the new note through the original MidiCv_NoteOn/Off functions.
- Releasing all held notes lowers the generated gate.

Known first-version limitations:
- Use the front-panel switch in one-voice mode for the clearest first test.
- Gate OFF and ON occur back-to-back; pitch advances correctly, but some
  envelopes may not visibly retrigger until a timed gate-gap is added.
- ARP mode is not stored in EEPROM.
- This build has compiled successfully on Stephen's Mac AVR toolchain.
- Hardware behavior of the arpeggiator itself still needs the first test.

First hardware test:
1. Flash the firmware.
2. Put the module in one-voice mode.
3. Confirm LIVE mode works.
4. Briefly press Program to enter ARP UP.
5. Hold C, E, and G after entering ARP mode.
6. Feed a slow external clock into the former Clock Out jack.
7. CV should advance C -> E -> G -> C; gate should remain active.
