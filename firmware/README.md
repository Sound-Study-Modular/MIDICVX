# MIDICVX v1.0.1 firmware

This directory is the release location for the tested v1.0.1 application HEX and WAV update image.

- `midi_cv_x.hex` — AVR application image
- `MIDICVX_v1.0.1.wav` — audio-bootloader update image

Source code is in the repository root. Bootloader source and tools are in `bootloader/`. ISP programming scripts are in `programmers/`.
